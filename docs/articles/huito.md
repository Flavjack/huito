# Huito

***Huito*** es un software de código abierto implementado en el lenguaje
de programación R para el diseño de etiquetas de forma flexible y
reproducible. El paquete lleva este nombre, ya que el fruto del árbol
del ***huito*** (*Genipa americana*) es usado por los nativos amazónicos
por sus propiedades colorantes para teñir telas y pintarse el cuerpo
(Figure [1](#fig:idbl2tuxtg6f7n)).

## Problema

La calidad de datos inicia desde la colecta de la información, y en
muchos casos no se le presta la debida importancia a este proceso. El
desarrollo de etiquetas puede ayudar a reducir el error en la colecta y
también acelerar el análisis de los datos (Figure
[2](#fig:kixvd7qxjm1q38u)).

## Alternativa

***Huito*** permite el desarrollo de etiquetas reproducibles y
personalizadas de acuerdo a los requerimientos del usuario. Cada
elemento en la etiqueta es adicionado por capas, respetando el orden de
acuerdo a su jerarquía en el código.
