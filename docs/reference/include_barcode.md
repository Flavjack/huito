# Barcode layer

Insert barcode in label

## Usage

``` r
include_barcode(
  label,
  value,
  size,
  position = NA,
  type = "static",
  color = "auto",
  units = "cm"
)
```

## Arguments

- label:

  label output

- value:

  column or path

- size:

  image size

- position:

  position coordinate

- type:

  type of entry: dynamic or static

- color:

  image color

- units:

  units for the label options

## Value

data frame
